# Кодекс поведения / Code of Conduct

Мы хотим, чтобы в этом проекте можно было спокойно задавать вопросы, присылать
патчи и ошибаться. Правила простые и распространяются на issues, pull requests,
discussions, code review и любые другие пространства проекта.

We want this project to stay a place where asking questions, sending patches and
making mistakes are all fine. These rules apply to issues, pull requests,
discussions, code review and every other project space.

## Ожидаемое поведение

- Критикуйте код и решения, а не людей.
- Предполагайте добросовестность: у собеседника может быть другой дистрибутив,
  другое железо и другой уровень опыта.
- Пишите по-русски или по-английски — как удобнее; просить перевести — нормально.
- Не публикуйте чужие персональные данные: адреса, аккаунты, логи с e-mail,
  скриншоты с реальными учётными записями.
- Не публикуйте эксплойты для уязвимостей — для этого есть
  [Security Advisories](https://github.com/Blqd/urnetwork-client/security/advisories/new).

## Недопустимое поведение

- Оскорбления, травля, дискриминация по любому признаку, угрозы.
- Спам, реклама, накрутка звёзд и «взаимные» подписки.
- Публикация чужих секретов, токенов и персональных данных.
- Политические и религиозные споры вне технической темы проекта.
- Настойчивое игнорирование просьб мейнтейнера прекратить нежелательное поведение.

## Модерация

Мейнтейнер может отредактировать или удалить сообщение, закрыть issue или PR,
заблокировать участника. Решение можно оспорить — напишите приватно.

## Как сообщить о нарушении

Напишите мейнтейнеру (@Blqd) приватно — через
[Security Advisory](https://github.com/Blqd/urnetwork-client/security/advisories/new),
если нужно сохранить конфиденциальность, либо обычным сообщением в GitHub.
Укажите ссылку, дату и что именно произошло. Все обращения рассматриваются
конфиденциально.
